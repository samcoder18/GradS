# Полноценный общий чат Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в общий чат доски постоянные фото и голосовые заметки, ответы, реакции и доступный полноэкранный режим.

**Architecture:** Сохранить текущие таблицы комментариев и расширить их метаданными вложений и reply-связью. Использовать Supabase Storage для файлов, RPC для сообщений/реакций, а DOM-клиент разделить на небольшие функции рендера и управления composer-состоянием внутри существующего `createAuditApp`.

**Tech Stack:** Vanilla JavaScript modules, semantic HTML, CSS, Vitest + JSDOM, PostgreSQL/Supabase RPC and Storage.

**Spec:** `docs/superpowers/specs/2026-08-20-full-chat-design.md`

## Global Constraints

- Existing board capability token remains only in the URL fragment and is never sent as a query parameter.
- Existing text comment RPCs and their public contracts remain backward-compatible.
- User-authored content is rendered with `textContent`; no HTML interpolation.
- Media is limited to image/audio MIME types, 5 attachments per message, and 8 MB per file.
- Mutation controls stay disabled while a write or upload is pending and recover after errors.
