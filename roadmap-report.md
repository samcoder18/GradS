# Стратегия развития сайта «Сладкий Град»: конверсия, престиж, запуск

**Дата:** 20.08.2026
**Связанный документ:** `AUDIT.md` (технический аудит, 19.08.2026)
**Рамка:** концепт «Виртуальный офис» не меняется — документ касается только публичного лендинга и инфраструктуры вокруг него.

## 1. Текущая воронка: диагноз

Сайт — B2B-лендинг производителя напитков. Целевое действие — оптовая заявка. Разложим страницу по AIDA:

| Стадия | Что есть сейчас | Чего не хватает |
|---|---|---|
| **Attention** | Сильный hero с продуктом, ценой от 50 ₽, двумя CTA | Конкретика «для кого» (дистрибьютор? розница? хорека?) |
| **Interest** | Карусель 7 вкусов, bento литровых хитов, Gudis | Условия опта, форматы/объёмы, логистика |
| **Desire** | Манифест, производство во Владикавказе | Социальное доказательство, сертификаты, кейсы, цифры клиентов |
| **Action** | CTA = mailto-ссылка, телефон, WhatsApp в футере | Настоящая форма заявки, снижение трения, обработка возражений (FAQ) |

**Главный вывод:** сайт красиво продаёт *продукт*, но не продаёт *сделку*. Оптовик пришёл не любоваться бутылками — ему нужны условия, маржа, минимальная партия, сроки и подтверждение надёжности. Сейчас всё это отсутствует, а целевое действие — «напишите нам на почту сами» — это максимальное трение.

**Вторая проблема:** ноль доверительных сигналов. Нет реквизитов, сертификатов, клиентов, отзывов. Для опта, где первая сделка — это десятки тысяч рублей и риск, это критично.

## 2. Новые блоки (приоритизировано)

Приоритет: **P1** — прямо влияет на конверсию, **P2** — престиж/доверие, **P3** — функциональность/вау-эффект.

### P1-1. Блок «Условия для опта» — самый важный новый блок

Разместить между bento-хитами и манифестом (или сразу после Gudis, перед CTA). Контент:

- Ценовые тиеры: «от 50 ₽ — от 1 короба / от 48 ₽ — от 10 коробов / индивидуально — от паллеты» (реальные цифры предоставляет клиент).
- Минимальная партия (MOQ).
- Отсрочка платежа (в «офисе» уже фигурирует «14 дн» — публично заявить можно только если это правда).
- Логистика: доставка по РФ/СНГ, самовывоз из Владикавказа, срок отгрузки.
- Что получает партнёр: POS-материалы, фотоконтент, поддержка бренда.

Формат: 3–4 тира карточками или таблицей «формат сотрудничества». Это блок, который конвертирует.

### P1-2. Рабочая форма заявки (замена mailto-CTA)

Сейчас «Оформить заказ» открывает почтовый клиент — половина мобильных пользователей на этом теряется. Нужна inline-форма или модалка:

- Поля: имя, телефон, тип бизнеса (дистрибьютор / розница / хорека / мероприятие), интересующий объём, город.
- Отправка: простейший вариант без бэкенда — Formspree/Netlify Forms/Web3Forms; свой вариант — Telegram-бот или Google Apps Script → таблица. Для GitHub Pages (статика) серверless-endpoint — единственный путь.
- Обязательно: чекбокс согласия на обработку ПДн + ссылка на политику (см. чеклист запуска).
- После отправки: честное подтверждение + «или напишите сразу в WhatsApp».

### P1-3. FAQ (снятие возражений)

Аккордеон из 5–7 вопросов перед финальным CTA: минимальный заказ, сроки отгрузки, работа с новыми клиентами, самовывоз, документы (УПД, ЕАС), эксклюзив по региону, дегустационные образцы. Побочный эффект — SEO-разметка FAQPage (расширенный сниппет в выдаче).

### P2-1. Социальное доказательство: «Где уже продаётся»

- Полоса логотипов сетей/магазинов/кафе, где стоит продукт (только реальные, с разрешения).
- Если логотипов пока мало — 2–3 коротких кейса: «Кофейня X, Владикавказ: берём 20 коробов в месяц, топ-продаж — мохито» + фото точки.
- Цифры: «N точек продаж в M городах» — только реальные, без выдуманной точности.

### P2-2. Блок «Качество и производство» — престиж

Расширить/углубить секцию о производстве:

- Вода: источник, артезианская скважина/родник, показатели анализа воды Gudis (минерализация мг/дм³ — реальные данные с этикетки).
- Документы: декларации ЕАС, ГОСТ/ТУ — можно с иконками документов и ссылками на PDF.
- Производство: фото цеха/линии розлива (заказать фотосессию — см. чеклист), мощность (бутылок/час).
- Это же блок «для проверяющих»: оптовики всегда проверяют легитимность производителя.

### P2-3. «Попробуйте перед заказом»

Плашка: «Бесплатный дегустационный набор для первых партнёров» или «Приезжайте на дегустацию на производство». Очень сильный триггер в опте — снимает главный риск («а вдруг невкусно/не пойдёт»). Связать с LocationSection.

### P3-1. Калькулятор маржи для ритейлера

Интерактивный мини-инструмент: «Закупка 50 ₽ → полка 89 ₽ → маржа 78% / X ₽ с короба». 3 слайдера (цена закупки, цена полки, объём в месяц) → «ваша прибыль в месяц». Дешёвый в разработке, сильно цепляет ритейлера и даёт повод оставить контакт («Получить точный расчёт на почту»).

### P3-2. Квиз вместо/в дополнение к форме

«Подберём условия за 30 секунд»: 3 вопроса (тип бизнеса → объём → город) → контакт. Квизы стабильно дают конверсию выше классической формы в B2B-опте.

### P3-3. Sticky-элементы

- Мобильный sticky-CTA («Оформить заказ» + WhatsApp) внизу экрана после hero.
- WhatsApp-виджет/плавающая кнопка — для этого продукта мессенджер, вероятно, конверсионнее почты.

### Что НЕ добавлять

- Блог/новости без ресурса на ведение — мёртвый раздел хуже отсутствующего.
- Онлайн-оплату/корзину — опт так не работает, лишняя сложность.
- Слайдер «наши награды» без реальных наград.

## 4. Ожидаемый эффект по целям

- **Конверсия:** P1-1 + P1-2 + P1-3 + P3-3 — основной вклад. Типовой прирост от замены mailto на форму в B2B-опте — кратный.
- **Престиж:** P2-1 + P2-2 + фотосессия производства + реквизиты в футере.
- **Функциональность:** P3-1 (калькулятор), P3-2 (квиз), рабочая форма, sticky-CTA.

- [ ] Регистрация: Яндекс.Вебмастер + Google Search Console, подтверждение, отправка sitemap, переезд (если сайт уже индексировался на github.io — запрос на переезд/каноникализация).

## 6. Предлагаемый порядок работ (3 итерации)

1. **Итерация 1 (быстрые деньги):** тех. исправления P0/P1 из AUDIT.md → блок «Условия для опта» → рабочая форма → FAQ → реквизиты в футере → sticky-CTA. Уже конверсионный сайт.
2. **Итерация 2 (доверие и запуск):** фотосессия → блок «Качество и производство» → соц. доказательство → домен + хостинг + HTTPS → SEO-база → Метрика → юр. документы → запуск.
3. **Итерация 3 (рост):** калькулятор/квиз → кейсы → SEO-контент → A/B-итерации по данным Метрики.
